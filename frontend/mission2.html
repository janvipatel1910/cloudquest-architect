DEPLOYMENT STAGE 1

Distribute Customer Traffic

ShopWave needs a highly available entry point that distributes incoming HTTP and HTTPS traffic across healthy application instances.

🎯 Your Task

  • Create an Application Load Balancer.
  • Place the load balancer across multiple Availability Zones.
  • Create a target group for the ShopWave EC2 application instances.
  • Configure health checks for the application targets.

💡 Why This Matters

The Application Load Balancer provides one entry point and sends requests only to healthy registered targets.

DEPLOYMENT CHECK

Verify Traffic Distribution

Which component should receive incoming customer web traffic before the ShopWave EC2 application instances?

DEPLOYMENT STAGE 2

Scale the Application with Demand

ShopWave must automatically add or remove application capacity as customer demand changes.

🎯 Your Task

  • Create an EC2 launch template.
  • Create an Auto Scaling group.
  • Distribute instances across multiple Availability Zones.
  • Attach the Auto Scaling group to the load balancer target group.
  • Configure a scaling policy based on application demand.

💡 Why This Matters

Auto Scaling adjusts application capacity while the load balancer distributes requests across the available healthy instances.

DEPLOYMENT CHECK

Verify Automatic Scaling

ShopWave traffic suddenly increases. Which AWS capability should automatically increase the number of EC2 application instances?

DEPLOYMENT STAGE 3

Deploy the Managed Database

ShopWave needs a managed relational database for structured customer, product, and order data.

🎯 Your Task

  • Create an Amazon RDS database.
  • Place the database in private network resources.
  • Configure appropriate availability for the workload.
  • Allow database connections only from the application tier.

💡 Why This Matters

Amazon RDS manages common database administration tasks while providing a relational database for the application.

DEPLOYMENT CHECK

Verify the Database Choice

Which service provides the managed relational database required by ShopWave?

DEPLOYMENT STAGE 4

Protect the Application Tier

Customers should reach the application through the load balancer rather than connecting directly to the EC2 application instances.

🎯 Your Task

  • Create a security group for the Application Load Balancer.
  • Create a separate security group for the application instances.
  • Allow application traffic to the EC2 tier from the load balancer security group.
  • Avoid exposing the application instances directly to customer web traffic.

💡 Why This Matters

Security-group references can restrict the application tier so requests arrive through the approved load-balancing layer.

DEPLOYMENT CHECK

Verify Application Access

What should the EC2 application security group use as the source for application traffic?
