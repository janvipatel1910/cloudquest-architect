# Mission 01 — Launch Day

## Mission Goal

Teach learners how to choose and deploy a secure, low-maintenance,
cost-conscious AWS architecture for a static website.

The learner must think like a Solutions Architect rather than simply
follow deployment instructions.

---

## Customer Scenario

A small startup is preparing to launch its first public website.

The website contains:

- HTML
- CSS
- JavaScript
- Images

The company expects visitors from the UK and other countries.

The customer requires:

- Low cost
- High availability
- Fast global delivery
- HTTPS
- Minimal operational overhead
- No unnecessary server management
- The website origin should not be directly exposed to the public

Your job is to design the AWS solution.

# Clue System

At the beginning:

Architecture Clues: 0 / 5

Correct answers unlock clues.

Wrong answers do NOT reveal the correct answer immediately.

Instead, the learner receives an architecture hint and must retry.

## Clue 1
Static object storage / website origin

## Clue 2
Global content delivery

## Clue 3
HTTPS / certificate

## Clue 4
DNS / custom domain

## Clue 5
Private origin access

---

# Architecture Board

After all five clues are collected, the Architecture Board unlocks.

The learner must correctly construct the solution using the unlocked
AWS components.

Expected architecture concepts:

User
↓
DNS
↓
CloudFront
↓
Private S3 Origin

HTTPS must be correctly configured.

The learner should discover the exact AWS services through the game,
rather than being shown the completed architecture beforehand.

---

# Architect Review

The submitted architecture is evaluated against:

1. Security
2. Global performance
3. Availability
4. Cost-conscious design
5. Operational overhead
6. Correct AWS service placement

If any requirement fails:

ARCHITECTURE NOT APPROVED

The learner receives a targeted hint and can modify the architecture.

The deployment stage remains locked.

If all requirements pass:

ARCHITECTURE APPROVED

AWS Deployment Mission unlocked.

---

# Deployment Mission

The learner must build the approved architecture in AWS.

The game should not count architecture theory alone as project
completion.

The learner must provide or complete defined validation evidence.

---

# Completion Rule

Mission 01 is complete only when:

- All five clues are unlocked
- Architecture Review passes
- Required AWS deployment is completed
- Deployment validation passes

Then:

Mission 01 — COMPLETE
XP awarded
Mission 02 — UNLOCKED
